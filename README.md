# ডিজিটাল ভূমি সেবা পোর্টাল

> **এক জমি, এক যাচাইযোগ্য ইতিহাস — প্রতারণার আগেই সত্য জানুন।**
> LandTech Innovation Hackathon ২০২৬ · ট্র্যাক: *Digital Land Records, Verification & Digitization*

একটি বাংলা-ভাষার ভূমি পোর্টালের কার্যক্ষম প্রোটোটাইপ। সাব-রেজিস্ট্রি অফিস, ব্যাংক, ডিসি অফিস, আদালত ও নাগরিক — পাঁচ পক্ষ একই ডেটা দেখে; জমিতে বন্ধক, নিষেধাজ্ঞা, খাস/অধিগ্রহণ বা অপেক্ষমান নামজারি থাকলে সিস্টেম দলিল সম্পাদনই আটকে দেয়; আর প্রতিটি জমির ইতিহাস SHA-256 হ্যাশ চেইনে বাঁধা, তাই গোপনে বদলালে ধরা পড়ে।

- **লাইভ ডেমো:** `[আপনার Vercel লিংক এখানে বসান]`
- **কনসেপ্ট পেপার:** `Concept-Paper-Digital-Bhumi-Seba-Portal.pdf`

> ⚠️ **সব ডেটা কাল্পনিক।** কোনো বাস্তব ব্যক্তি, এনআইডি, ফোন নম্বর বা জমির রেকর্ড ব্যবহার করা হয়নি; কোনো সরকারি সিস্টেমে সংযোগ নেই।

## ৪. চালানোর নিয়ম

### ক) অনলাইনে ডিপ্লয় (কমান্ড ছাড়া — সহজতম)
1. প্রজেক্ট ফোল্ডারটি **GitHub Desktop**-এ `Add local repository` করে GitHub-এ **Publish** করুন।
2. [vercel.com/new](https://vercel.com/new) → রিপো ইমপোর্ট → Framework Preset **Other** (Build/Output খালি)। Environment Variable দিন: `JWT_SECRET` = যেকোনো ৪০+ অক্ষরের র‍্যান্ডম লেখা।
3. Vercel → **Storage → Create Database → Neon** → প্রজেক্টে Connect (Custom Prefix খালি, “Create database branch” টিক বন্ধ)। `DATABASE_URL` নিজে থেকে যুক্ত হবে।
4. Neon **SQL Editor**-এ প্রথমে `db/schema.sql`, তারপর `db/seed.sql`-এর লেখা পেস্ট করে **Run**।
5. Vercel → Deployments → **Redeploy**। সাইট খুলে লগইন করুন।

বিস্তারিত ধাপ ও সমস্যার তালিকা: [`DEPLOY.md`](DEPLOY.md)।

### খ) নিজের পিসিতে চালানো
**লাগবে:** Node.js 22, Git, একটি Neon ডাটাবেস।
```bash
git clone <রিপোজিটরি-লিংক> && cd <ফোল্ডার>
npm install

# .env.example কপি করে .env বানান, তারপর দুটি মান বসান:
#   DATABASE_URL=<Neon কানেকশন স্ট্রিং>     JWT_SECRET=<npm run gen:secret এর ফল>
npm run db:setup        # টেবিল + ডেমো ডেটা বসায়
npm run db:check        # সংযোগ ও hash chain যাচাই

npm run dev             # = vercel dev  → http://localhost:3000  (প্রথমবার vercel login/link চাইবে)
```
**ডাটাবেস ছাড়াই** সব API পরীক্ষা করতে: `npm test` (আসল PostgreSQL-এর ইন-প্রসেস সংস্করণে ৮৬টি যাচাই)।

### গ) যাচাইয়ের কমান্ড
| কমান্ড | কাজ |
|---|---|
| `npm run check` | ফাংশন সংখ্যা (১২-র বেশি হলে ফেল), rewrite, ফ্রন্টএন্ডের API URL, সিনটেক্স |
| `npm test` | ভূমিকা-লঙ্ঘন, ব্লকিং নিয়ম, ৭ দলিল, নামজারি, হ্যাশ চেইন, ঋণ, টোকেন-গেট, rate-limit |
| `npm run smoke -- <url>` | ডিপ্লয়ের পর লাইভ সাইটে শুধু-পড়া পরীক্ষা |
| `npm run db:reset` | ডেমো ডেটাসহ ডাটাবেস নতুন করে বানায় (সব মুছে) |
